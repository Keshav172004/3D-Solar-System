 3D Solar System – Keshav Mittal

This is an interactive 3D Solar System implemented using Three.js.

Features
- Textured and orbiting planets
- Sliders to adjust orbit speeds
- Pause/Resume to pause/resume planet motion
- Auto-Rotate toggle for rotating the camera
- Dark/Light mode switcher
- Responsive design (supports mobile as well)

How to Run

Option 1: Using VS Code
1. Install [Visual Studio Code](https://code.visualstudio.com/)
2. Install the **Live Server** extension from VS Code marketplace
3. Open the project folder in VS Code
4. Right-click `index.html` → Click **"Open with Live Server"**
5. Your browser will open and display the Solar System

Option 2: Direct Open
1. Open `index.html` in your browser (not guaranteed to load textures due to CORS)

Summary
✅ Download → ✅ Open in VS Code → ✅ Install Live Server → ✅ Open index.html → Done.
